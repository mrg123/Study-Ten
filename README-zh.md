# Study-Ten
学习十个小时

## 应用简介
"学习10小时"是一款专注学习应用，通过奖励机制鼓励用户坚持学习。应用采用简洁的极简主义设计，帮助用户专注于学习任务，减少外部干扰。

## 核心功能

- **专注计时器**：可自定义的专注时间，默认为90分钟
- **奖励机制**：在专注过程中随机触发奖励，播放提示音以鼓励用户休息[休息等于奖励]
- **自定义设置**：可调整专注时间、奖励参数、提示音和主题
- **多语言支持**：支持中文和英文

## 使用指南

### 首页
- 点击中央圆圈开始专注计时
- 长按圆圈结束专注
- 向上滑动进入设置页面

## 技术实现
- 编程语言：Swift
- 框架：SwiftUI
- 数据存储：SwiftData
- 设计规范：符合苹果人机交互设计规范
