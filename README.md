# Study-Ten
Study for Ten Hours

## App Introduction
"Study for 10 Hours" is a focus learning application that encourages users to persist in studying through a reward mechanism. The app features a clean minimalist design to help users concentrate on learning tasks and reduce external distractions.

## Core Features

- **Focus Timer**: Customizable focus duration, default is 90 minutes
- **Reward Mechanism**: Randomly triggers rewards during focus sessions, plays notification sounds to encourage breaks [Break equals reward]
- **Custom Settings**: Adjustable focus duration, reward parameters, notification sounds and themes
- **Multi-language Support**: Supports both Chinese and English

## User Guide

### Home Page
- Tap the center circle to start focus timer
- Long press the circle to end focus
- Swipe up to enter settings page

## Technical Implementation
- Programming Language: Swift
- Framework: SwiftUI
- Data Storage: SwiftData
- Design Guidelines: Complies with Apple's Human Interface Guidelines
